# Life Mirror

毎日の生活習慣を仮想の部屋とアバターに反映する、Next.js 製の生活改善アプリです。

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開いてください。

## 実装済み

- 達成度が反映されるマイルームとライフスコア
- SQLite によるタスクの永続化
- タスクの追加・編集・削除・完了切り替え
- 目標回数まで1回ずつ積み上げる日次実行ログ
- カレンダーからの過去記録閲覧・修正
- 家事の未消化日数と内容に応じた、床・ごみ・キッチンの変化
- 睡眠・食事記録に連動する10段階アバターと瞬き
- カテゴリー別フィルター
- 生活バランスと継続状況のレポート
- 達成状況に応じたアドバイス
- PC・タブレット・スマートフォン対応UI
- パスワードハッシュとHttpOnlyセッションCookieを使ったログイン・新規登録
- ユーザーごとに分離されたタスクと生活記録

データベースは初回起動時に `data/life-mirror.db` として自動生成されます。現在のアドバイスはルールベースです。外部AI APIへ接続する場合は、`Room` コンポーネントのアドバイス表示をサーバー側のAI API Routeへ置き換えてください。
